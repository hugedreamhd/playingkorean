📚 앱 명칭: 플레잉코리안 (가제)
"문장으로 익히고, 영어로 확인하는 똑똑한 국어사전 퀴즈"
1. 핵심 기능 (Core Functions)
동음이의어 문맥 퀴즈:
국립국어원 사전의 표준 예문을 활용해 ( ) 안에 들어갈 알맞은 단어를 맞힙니다.
예: "밤(Night)에 잠이 안 온다" vs "밤(Chestnut)을 삶았다"를 문장으로 구분.
다국어 학습 피드백 (한-영 결합):
정답 확인 시, 해당 단어의 **영어 발음(Bam)**과 **영문 정의(Night / Chestnut)**를 동시에 노출.
한국어 단어가 가진 여러 의미를 영어로 매칭하여 어휘력을 확장합니다.

오프라인 로컬 사전 DB:
국립국어원 오픈 데이터를 SQLite에 내장하여, 네트워크 연결(SK 1기가 망 등)에 상관없이 즉각적인 반응 속도를 제공합니다.
학습 위젯 (바로메모 기술 응용):
앱을 켜지 않아도 홈 화면 위젯에서 '오늘의 단어'와 '오늘의 퀴즈'를 바로 확인.
이전 개발 경험을 살려 위젯 업데이트 시 배경이 하얗게 튀는 깜빡임 현상을 완벽히 해결한 다크 모드 위젯 제공.

3. 기술적 차별점 (Tech Specs)
데이터 정제 기술: 국립국어원 사전 데이터에서 예문 내 정답 단어를 자동으로 가리고, 관련 영어 뜻을 매칭하는 파싱(Parsing) 로직.
테마 시스템: app_theme.dart를 활용해 눈이 편안한 다크 블루/블랙 테마(#1A1C1E) 기본 적용.
성능 최적화: 대용량 사전 데이터를 검색할 때 딜레이가 없도록 DB 인덱싱(Indexing) 최적화.
